# @ocelescope/case-centric-alignments

An [Ocelescope](https://www.ocelescope.org) frontend module for computing and
viewing case-centric alignments of the current object-centric event log.

Select a Petri net (or let Alpha+++ discover one), run the alignment, and
explore the results as a list of aligned variants or on the net.

Requires the `ocelescope-module-case-centric-alignments` backend module.
